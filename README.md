# Clima em Chamas

O Clima em Chamas é um projeto desenvolvido para acompanhar dados relacionados ao clima e às queimadas no Brasil. O site reúne informações sobre focos de calor e temperatura, permitindo visualizar e comparar esses dados por meio de gráficos.

## Funcionalidades

- Gráfico de temperatura média por estado.
- Gráfico de focos de calor por estado.
- Gráfico de distribuição de focos de calor por bioma.
- Filtros para consultar os dados.
- Área de anotações, com opções para criar, editar, visualizar e excluir registros.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Chart.js
- Back4App
- API Open-Meteo
- Dados do INPE

## Fontes de dados

- [INPE – Programa Queimadas](https://www.gov.br/inpe/pt-br/assuntos/ultimas-noticias/queimadas)
- [Open-Meteo](https://open-meteo.com/)

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

O projeto utiliza dados locais do INPE e consulta a API Open-Meteo para obter informações de temperatura.

# Dados de focos de calor

O arquivo `focos-2025.json` contém uma versão agregada da base oficial de focos de referência do Programa Queimadas do INPE para 2025.

- Total de registros processados: 136.393
- Agregações: por estado, por bioma e por estado/bioma
- Fonte: https://data.inpe.br/queimadas/portal/dados-abertos/
- Arquivo original: `focos_br_ref_2025.zip`

A base foi agregada para reduzir o tamanho transferido pelo site. Os gráficos de focos exibem dados de 2025; se o intervalo selecionado não incluir 2025, os gráficos informam que não há dados disponíveis para aquele período.

**Importante:** foco de calor detectado não é a mesma coisa que área queimada.
